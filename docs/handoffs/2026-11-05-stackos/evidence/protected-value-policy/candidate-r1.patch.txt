+# Engineering protected-value policy
+
+Status: implementation candidate, awaiting independent logic/security review.
+No behavior/security tests or live model runs establish acceptance yet.
+
+## Owner and scope
+
+`stackos.artifacts.protected_values.ProtectedValuePolicy` is an opt-in generic
+policy beside the existing artifact redaction owner. The existing
+`redact_secret_text` and `redact_secrets` behavior is unchanged for other callers.
+Engineering adapters in `plugins/engineering/scripts` opt in. Domain sequencing,
+role/model identity, approval before test writing, custody and recovery budgets
+remain in those adapters and their existing run-plan owners.
+
+The controller captures its existing sensitive inherited environment-value set
+once per invocation, without reading authentication/session files or discovering
+additional credentials. That immutable policy and the captured allowlisted
+environment are reused for the invocation, including recovery. New credentials
+introduced after capture are not discovered. Empty/missing helper transport holds;
+an explicitly captured empty set is valid.
+
+## Admission and retention
+
+The policy checks raw strings and one normalized view of their original escape
+sequences. Supported representations include mixed raw/JSON Unicode spellings,
+JavaScript hex, fixed/braced Unicode, identity and legacy octal escapes,
+escaped backslashes, UTF-16 surrogate pairs and LF/CR/CRLF/U+2028/U+2029 line
+continuations. Produced backslashes are never decoded again. JSON values are
+also checked after JSON decoding at the observation, tool, model-answer and
+record boundaries. It does not recognize arbitrary computed, concatenated,
+encrypted, compressed, base64 or URL-encoded representations.
+
+With a nonempty protected set, malformed or unsupported escape-like input is
+held. This is conservative lexical inspection, not a language parser: literal
+prose/Python/regex fragments containing incomplete `\u`, `\x`, a trailing
+backslash or an unpaired surrogate escape may be held even when harmless in
+their intended context. Independent review and subsequent benign-flow checks
+must assess this applicability limit. With an empty set there is no known-value
+normalization to perform; Unicode, type, size and structure checks still apply,
+along with the separate unchanged label scanner and JSON decoding rules.
+
+Limits are explicit: at most 256 protected values and 65,536 transport bytes;
+20,000,000 UTF-8 bytes per string; 24,000,000 aggregate string bytes, 100,000
+visited nodes and depth 64 per structured value. Only JSON types, finite floats
+and integers of at most 256 bits are accepted; cycles and non-string object keys
+hold. Controller prompts and observation files retain the 200,000-byte input
+bound. Existing narrower broker/command/event bounds remain in force.
+
+Requirements and assembled prompts are rejected before durable dispatch intent
+or model input. Decoded observation specifications, argv and tool arguments are
+rechecked before confined/unconfined execution and model-requested commands.
+Tool/command results are checked before a dynamic-tool response is sent to the
+host. Source snapshots, old/current changed-source text, broker reads/writes and
+paths use the same policy while preserving original bytes and existing strict
+label rejection. There is no AST admission exemption: harmless JavaScript
+assignments caught by that strict scanner remain held.
+
+Retention withholds an entire unsafe string, avoiding partial value fragments.
+Unsafe keys are omitted rather than rewritten into colliding keys. Progress,
+errors and receipts are sanitized, then independently validated before records
+are written. Typed path/digest evidence is encoded before label-based key
+redaction; the canonical run-plan secret-key policy is not weakened. Prior
+history that fails the current invocation policy is held, not rewritten.
+Extremely short protected values can overlap diagnostics or protocol metadata;
+if even a replacement/diagnostic is unsafe, admission exits without emitting it.
+
+## Private helper transport and isolation
+
+Ordinary worker, reviewer and confined-observation helpers receive the same
+bounded policy through an anonymous socket pair. Only a descriptor number, never
+policy material, is placed in argv. The supervisor passes it only to the trusted
+helper and immediately closes its copy. The controller writes once and closes;
+the helper consumes through EOF, validates and closes its descriptor before any
+native probe or app-server startup. No policy file, environment variable, model
+input or host record is created. Missing, truncated, malformed or oversized
+transport holds. Supervisor process-group custody and the existing filesystem
+and no-network permissions remain unchanged.
+
+The controller's Git subprocess and native-launcher probe use filtered
+environments too. This policy does not expand the existing host auth reference:
+the pre-existing helper references the operator's login file but does not read or
+copy its contents for protected-value discovery.
+
+The persistent app-server owns its own internal output/session storage.
+`Server.receive` can validate only after that server supplies a message; it
+cannot prevent an internally generated model answer or command result from
+having been stored by the host first. Unsafe inputs/tool responses and policy
+material are not sent to the host. Received output is checked before any further
+StackOS action, record or disclosure. Prevention of host-internal pre-adapter
+retention is not established by this implementation; exact thread continuity
+is preserved rather than replaced by a different host lifecycle.
+
+## Review and verification boundary
+
+Fresh independent review must inspect original requirements and actual source
+before a fresh test session. Static lint/syntax success is not behavioral proof.
+Post-approval checks must cover synthetic mixed encodings and one-pass behavior,
+decoded argv/JSON and tool results, rejection before execution/disclosure/record
+writes, descriptor closure and argv/environment isolation, benign flows, role
+identity, approval gating and unchanged recovery history/budgets.
+
+This checkout is not installed. Helpers import the shared policy from the
+`stackos` package; the existing older venv/installed package does not contain it,
+and the filtered environment intentionally removes `PYTHONPATH`. A test session
+must prove candidate module paths and use an isolated explicit candidate
+bootstrap if needed. That is not proof of the installed flow, and does not
+authorize installing, changing the runtime, widening permissions or relaunching
+business work. The separate source-admission hold remains unresolved.

+"""Opt-in known-value admission, separate from label-based redaction.
+
+Normalization inspects original escape sequences once. It is deliberately not a
+language parser, evaluator, encryption detector, or source-admission exemption.
+"""
+
+from __future__ import annotations
+
+import json
+import math
+from dataclasses import dataclass, field
+from typing import Any
+
+MAX_POLICY_BYTES = 65_536
+MAX_TEXT_BYTES = 20_000_000
+MAX_STRUCTURE_BYTES = 24_000_000
+MAX_NODES = 100_000
+MAX_DEPTH = 64
+_HELD = "[withheld by protected-value policy]"
+_HEX = frozenset("0123456789abcdefABCDEF")
+
+
+class ProtectedValueError(ValueError):
+    """Intentionally contains neither input excerpts nor policy fingerprints."""
+
+    def __init__(self):
+        super().__init__("protected-value admission held")
+
+
+def _normalized(text: str) -> str:
+    """Decode JSON/JS escapes once, then join UTF-16 surrogate pairs once.
+
+    Identity escapes include escaped punctuation and non-ASCII characters.
+    Legacy octal consumes at most three digits (two when starting with 4..7).
+    A produced backslash is data; it is never fed back into this decoder.
+    """
+    out = []
+    index = 0
+    simple = {"b": "\b", "f": "\f", "n": "\n", "r": "\r", "t": "\t", "v": "\v"}
+    while index < len(text):
+        char = text[index]
+        index += 1
+        if char != "\\":
+            out.append(char)
+            continue
+        if index == len(text):
+            raise ProtectedValueError()
+        char = text[index]
+        index += 1
+        if char in "\n\r\u2028\u2029":
+            if char == "\r" and text[index:index + 1] == "\n":
+                index += 1
+            continue
+        if char in simple:
+            out.append(simple[char])
+        elif char in "xu":
+            if char == "u" and text[index:index + 1] == "{":
+                end = text.find("}", index + 1, index + 8)
+                if end < 0:
+                    raise ProtectedValueError()
+                digits = text[index + 1:end]
+                index = end + 1
+            else:
+                width = 2 if char == "x" else 4
+                digits = text[index:index + width]
+                index += width
+                if len(digits) != width:
+                    raise ProtectedValueError()
+            if not digits or any(digit not in _HEX for digit in digits):
+                raise ProtectedValueError()
+            codepoint = int(digits, 16)
+            if codepoint > 0x10FFFF:
+                raise ProtectedValueError()
+            out.append(chr(codepoint))
+        elif char in "01234567":
+            digits = char
+            width = 3 if char in "0123" else 2
+            while len(digits) < width and text[index:index + 1] in tuple("01234567"):
+                digits += text[index]
+                index += 1
+            out.append(chr(int(digits, 8)))
+        else:
+            # JS identity escapes (including \\, quotes, /, 8 and 9).
+            out.append(char)
+    result = []
+    index = 0
+    while index < len(out):
+        point = ord(out[index])
+        index += 1
+        if 0xD800 <= point <= 0xDBFF:
+            if index == len(out) or not 0xDC00 <= ord(out[index]) <= 0xDFFF:
+                raise ProtectedValueError()
+            low = ord(out[index])
+            index += 1
+            result.append(chr(0x10000 + ((point - 0xD800) << 10) + low - 0xDC00))
+        elif 0xDC00 <= point <= 0xDFFF:
+            raise ProtectedValueError()
+        else:
+            result.append(chr(point))
+    return "".join(result)

+@dataclass(frozen=True, repr=False)
+class ProtectedValuePolicy:
+    """Immutable explicitly supplied values; never discovers credentials.
+
+    Input and normalization are bounded independently of the caller. Only JSON
+    types are accepted for structured admission. Retention withholds an entire
+    unsafe string; executable inputs must instead use require().
+    """
+
+    _values: tuple[str, ...] = field(repr=False)
+
+    def __post_init__(self):
+        if (
+            type(self._values) is not tuple
+            or len(self._values) > 256
+            or any(
+                type(value) is not str or not value or len(value) > MAX_POLICY_BYTES
+                for value in self._values
+            )
+        ):
+            raise ProtectedValueError()
+        try:
+            if sum(len(value.encode("utf-8")) for value in self._values) > MAX_POLICY_BYTES:
+                raise ProtectedValueError()
+            encoded = self.private_transport()
+        except (UnicodeError, ValueError):
+            raise ProtectedValueError() from None
+        if len(encoded) > MAX_POLICY_BYTES:
+            raise ProtectedValueError()
+
+    def __repr__(self):
+        return "ProtectedValuePolicy(<private>)"
+
+    def private_transport(self) -> bytes:
+        """For a private, non-persisted pipe only. Never log or put in argv/env."""
+        return json.dumps(list(self._values), ensure_ascii=True).encode("ascii")
+
+    @classmethod
+    def from_private_transport(cls, data: bytes) -> ProtectedValuePolicy:
+        if len(data) > MAX_POLICY_BYTES:
+            raise ProtectedValueError()
+        try:
+            values = json.loads(data)
+            if type(values) is not list:
+                raise ProtectedValueError()
+            return cls(tuple(values))
+        except (ValueError, TypeError, RecursionError):
+            raise ProtectedValueError() from None
+
+    def require_text(self, value: str) -> None:
+        if type(value) is not str or len(value) > MAX_TEXT_BYTES:
+            raise ProtectedValueError()
+        try:
+            if len(value.encode("utf-8")) > MAX_TEXT_BYTES:
+                raise ProtectedValueError()
+            # With no known values, there is no encoded representation to find.
+            # Preserve ordinary prose/source acceptance; decoded JSON still
+            # passes type, Unicode and traversal checks at its own boundary.
+            if not self._values:
+                return
+            if any(secret in value for secret in self._values):
+                raise ProtectedValueError()
+            normalized = _normalized(value)
+            if any(secret in normalized for secret in self._values):
+                raise ProtectedValueError()
+        except UnicodeError:
+            raise ProtectedValueError() from None
+
+    def _walk(self, value: Any, *, sanitize: bool) -> Any:
+        nodes = 0
+        size = 0
+        active = set()
+

+                    raise ProtectedValueError()

+            if item is None or type(item) in (bool, int):
+                if type(item) is int and item.bit_length() > 256:
+                    raise ProtectedValueError()
+                self.require_text(json.dumps(item))
+                return item
+            if type(item) is float and math.isfinite(item):
+                self.require_text(json.dumps(item))
+                return item
+            if type(item) not in (list, dict) or id(item) in active:
+                raise ProtectedValueError()
+            active.add(id(item))
+            try:
+                if type(item) is list:
+                    return [visit(child, depth + 1) for child in item]
+                result = {}
+                for key, child in item.items():
+                    if type(key) is not str:
+                        raise ProtectedValueError()
+                    safe_key = visit(key, depth + 1)
+                    safe_child = visit(child, depth + 1)
+                    if safe_key != key:
+                        # Never collide rewritten keys or retain secret key text.
+                        continue
+                    result[key] = safe_child
+                return result
+            finally:
+                active.remove(id(item))
+
+        return visit(value, 0)
+
+    def require(self, value: Any) -> None:
+        self._walk(value, sanitize=False)
+
+    def sanitize(self, value: Any) -> Any:
+        try:
+            result = self._walk(value, sanitize=True)
+        except ProtectedValueError:
+            result = _HELD
+        # Independently validate even fixed replacements (short protected values
+        # may overlap them). No unvalidated fallback reaches a durable boundary.
+        self.require(result)
+        return result
