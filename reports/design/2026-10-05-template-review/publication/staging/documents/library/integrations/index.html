How the catalog fits together

Plugins organize the work. Providers connect the tools.

A workflow can use several plugins and providers. The agent decides what should happen next. StackOS keeps the plan, authority, status, and receipts together while each provider performs its bounded part.

01

Start in your AI

Describe the job in Codex, Claude Code, Gemini CLI, or another connected client.

02

The agent chooses the next step

It reads the workflow state, selects the action, and supplies the relevant context.

03

Run the bounded action

StackOS scopes the call and resolves the configured credential. The provider performs the action, and StackOS records the result.
