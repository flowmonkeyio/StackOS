Common questions

LinkedIn API and StackOS.

What can the LinkedIn API integration do in StackOS?

The current catalog includes 1 LinkedIn API action across Content Distribution. The exact actions used depend on the workflow and approval rules.

Does StackOS replace LinkedIn API?

No. LinkedIn API remains the tool that performs its part of the job. StackOS organizes the workflow, keeps status and dependencies visible, and calls the tool only when the plan reaches the right approved action.
